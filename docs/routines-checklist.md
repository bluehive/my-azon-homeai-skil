# 計画B 定型アクション 実機検証チェックリスト

## フレーズ候補（短く・言い間違えにくいもの）
- [ ] 「テレビの時間」（プライムビデオ用）
- [ ] 「映画をみせて」（予備）
- [ ] 「歌をかけて」（YouTube用）
- [ ] 「歌の時間」（予備）

## カスタムアクション文面候補
- B1：「プライムビデオでアクション映画を再生して」
- B1予備：「プライムビデオを開いて」
- B2：「YouTubeで（チャンネル名）を再生して」 ※チャンネル名は着手時に特定
- B2予備：「YouTubeを開いて」

## 確認項目
- [ ] 定型アクションでテレビ（TCL）の電源がONになる（HDMI-CEC 設定を確認）
- [ ] 入力がFire TVに切り替わる
- [ ] カスタムアクションでアプリが起動する
- [ ] 一発で再生まで進むか／一覧表示で止まるか
- [ ] 確認質問が出ないか
- [ ] 電源OFFからの実行、Fire TVスリープからの実行の両方で動く
- [ ] 家族本人の声・話し方で認識される
- [ ] 停止（「止めて」）・音量の操作ができる

## 失敗時の代替
- 一発再生できない → 「〜を開いて」でアプリ起動まで＋リモコンの決定ボタン1回を紙で案内
- 電源が入らない → CEC設定見直し、またはFire TV Cubeの機器コントロール（IR）設定
- 認識されない → より短い/区別しやすいフレーズに変更
- 案内用の紙：フレーズを大きく書いてテレビ横に貼る。「うまくいかなければもう一度言う」と併記
